# Chain registry — folder name → display title (the platform's `unit` string).
#
# The chain ordinal lives in the FOLDER NAME, not the title. It is the TEACHING
# ORDER: the platform sorts every teacher's outline by catalogue path, across all
# courses in one list (B-42). Numbering is YEAR-BANDED (D46): ordinal = year × 100 +
# position within the year, so Y7 sorts first (701…), then Y8 (801…), and up to Y13
# (1301…). A new chain slots into its year without renumbering any other year.
# Renumbering a folder is safe: an activity's identity is its `key:`, not its path.
#
# Folders are FLAT: the platform takes the chain from the first path segment.
# Precedence for a file's unit: its own `unit:` wins, then this registry, then unset.
# A folder with no entry warns and fails --strict. Every chain in the graph is listed;
# only folders that exist are read. Import runs pass `--chain-registry <this file>`
# (platform be76a67), which wins over any copy in the catalogue root; a root copy
# is no longer needed, and the importer names one it shadows in the run header.
#
