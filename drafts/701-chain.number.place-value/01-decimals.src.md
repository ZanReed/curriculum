## Lesson {checkpoint}

Every [[digit]] in a number has a [[place value]]: what it is worth depends on its place. Left of the [[decimal point]] are the ones, tens and hundreds. Right of it, the places keep going, smaller and smaller. The first place after the point is [[tenth]]s, and the second is [[hundredth]]s.

So the [[decimal]] 3.45 means 3 ones, 4 tenths and 5 hundredths. You say it "three point four five".

```worked
title: Write 7 tenths, and then 7 hundredths, as a decimal
7 tenths: the 7 goes in the tenths place, the first place after the point.
There are no ones, so the ones place gets a 0. 7 tenths is 0.7.
7 hundredths: the 7 goes in the hundredths place, the second place after the point.
There are no tenths, so the tenths place gets a 0 to hold it. 7 hundredths is 0.07.
Same digit, different place. 0.07 is much smaller than 0.7: 7 hundredths is less than 1 tenth.
```

To compare two decimals, line up their decimal points, so that each place sits under the same place. Fill any empty place on the end with a 0: a 0 on the end doesn't change a decimal, because 5 tenths is the same as 50 hundredths. Then compare from the left. The first place where the digits are different decides.

```worked
title: Which is larger, 0.45 or 0.5?
Line up the points. 0.5 has no hundredths digit, so fill it with a 0: 0.5 = 0.50.
0.45 and 0.50. Ones: 0 and 0, the same.
Tenths: 4 and 5. They're different, so the tenths decide. 5 tenths is more than 4 tenths.
So 0.5 is larger. Another way to see it: 0.45 is 45 hundredths and 0.50 is 50 hundredths.
0.45 has more digits, but that doesn't make it larger. Only the places do.
```

The same two decimals, but now the tenths are the same.

```worked
title: Which is larger, 0.6 or 0.65?
Line up the points and fill the empty place: 0.6 = 0.60.
0.60 and 0.65. Ones: 0 and 0. Tenths: 6 and 6, the same, so keep going.
Hundredths: 0 and 5. They're different, so the hundredths decide.
So 0.65 is larger. This time the longer decimal is larger. That is because of its hundredths digit, not because it is longer.
```

```teacher-guide
## The sequence

One idea: each place after the point has its own value, so compare decimals place by place from the left. The first example is a minimal pair, 0.7 and 0.07: same digit, different place. Then three comparisons. 0.45 against 0.5 answers the long-jump hook. 0.6 against 0.65 is the deliberate opposite, where the longer decimal is larger, so no one leaves with "shorter wins". 2.3 against 2.28 adds ones in front.

## Watch for

- "More digits means larger" (0.45 > 0.5). Ask, "What is the 4 worth? And the 5?"
- Swinging the other way: "shorter means larger". The 0.6 and 0.65 example is for this.
- 6 hundredths written as 0.6. Ask which place is hundredths.
```
